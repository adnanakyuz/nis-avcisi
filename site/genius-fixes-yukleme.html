Genius Fixes Uploader — Privacy Policy & Terms

"Genius Fixes Yukleme" is a private desktop tool used only by the owner of the YouTube channel Genius Fixes (@geniusfixesHQ) to upload that channel's own videos.

What data it uses

With the owner's permission, the tool uses the YouTube Data API to upload videos, captions and thumbnails to the owner's own channel and to set their title, description, tags and publishing time. It does not read, collect or share data about any other user.

Where data is stored

The access token is stored only on the owner's own computer. Nothing is sent to any server other than Google/YouTube. No data is sold or shared with third parties.

Google policies

Use of information received from Google APIs adheres to the Google API Services User Data Policy. By using YouTube features you agree to the YouTube Terms of Service; see also the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
